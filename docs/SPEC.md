## §1. Продукт

«Fetchy» — десктопное GUI-приложение (обёртка над yt-dlp) для скачивания видео с YouTube и тысяч сайтов: вставка URL → выбор опций → очередь → история. Полный доступ к опциям yt-dlp через удобный UI, без терминала.

## §2. Платформы

- Windows 10/11 x64 (первоочередная).
- Linux X11 и Wayland (совместимость через JVM/Compose Desktop, без нативных API вёрстки).
- ОС/локали: английская и русская (EN/RU).

## §3. Функциональные требования

1. **Add** — вставка URL (http/https), валидация, разбор (превью: название, обложка, длительность), выбор пресета, расширенные опции (категории: формат, субтитры, аудио, плейлисты, прокси и всё остальное из реестра опций yt-dlp), запуск загрузки.
2. **Queue** — активные и стоящие в очереди загрузки: прогресс, скорость, ETA, позиция в плейлисте, отмена, повтор после ошибки, счётчики, ограничение параллелизма; восстановление очереди после перезапуска.
3. **History** — завершённые загрузки (успех/ошибка): поиск, фильтры, детали, путь к файлу, открытие папки, полный лог, человекочитаемое описание ошибки.
4. **Presets** — именованные наборы аргументов yt-dlp: CRUD, дублирование, редактор опций из реестра help, превью итоговой команды.
5. **Settings** — пути к бинарникам (yt-dlp/ffmpeg/ffprobe) с проверкой версий и скачиванием yt-dlp, параллелизм, тема, язык, прокси, каталог загрузок, cookies-файл, «О приложении».
6. **Tools** — Doctor (диагностика окружения), список экстракторов yt-dlp с поиском, Probe (ffprobe-метаданные локального файла).

## §4. Технические требования

- Процесс yt-dlp: без shell, UTF-8, `--ignore-config`, прогресс через `--newline` + `--progress-template`.
- Маскирование креденшалов в логах/командах/отчётах.
- Single-instance: второй запуск активирует существующее окно.
- Не бандлить yt-dlp/ffmpeg; лицензия MIT.
- Классы ошибок: `NOT_FOUND`, `NETWORK`, `AUTH_REQUIRED`, `GEO_BLOCKED`, `DRM_PROTECTED`, `PLAYLIST_PARTIAL`, `NO_SPACE`, `FFMPEG_MISSING`, `BINARY_MISSING`, `UNKNOWN`.
- Тесты: golden-фикстуры системного yt-dlp 2026.08.19 (help 896 строк, extractors 1752 строки), паритет EN/RU-строк.

## §5. Ограничения безопасности (§13 ТЗ, с правкой D15)

- **DRM (правка заказчика):** из исходного §13 удалён запрет «не обходить DRM и не добавлять функций для этого; для `--allow-unplayable-formats` показывать предупреждение». Вместо этого: класс ошибки `DRM_PROTECTED` → сообщение «Это видео защищено DRM, yt-dlp не может его скачать» + кнопка «Показать лог». Функций обхода DRM в приложении нет (yt-dlp сам отказывается от DRM-контента).
- Обход geo-блоков, капч, подписок и платных аккаунтов не реализуется (только штатные средства yt-dlp: cookies, прокси — по явной настройке пользователя).

## §11. Этапы (вход для плана)

1. Этап 0 — инфраструктура (git, Gradle, каталог версий, конвенции, скелет, CI).
2. Этап 1 — designsystem (тема M3 Expressive, компоненты, motion, витрина).
3. Этап 2 — core/ytdlp (бинарники, аргументы, парсеры, runner, классификатор ошибок).
4. Этап 3 — данные (SQLDelight), каркас приложения (DI/навигация/single-instance), экран Add, шедулер.
5. Этап 4 — Queue (список, управление, восстановление).
6. Этап 5 — History (список, детали, лог).
7. Этап 6 — Presets (CRUD, редактор опций).
8. Этап 7 — Settings (экран, персистентность, локализация).
9. Этап 8 — Tools, упаковка (jpackage), приёмка, полировка.

## §12. Приёмка

- [ ] Полный цикл: вставка URL → разбор с превью → очередь → файл на диске → запись в History.
- [ ] Прогресс в реальном времени: проценты, скорость, ETA; для плейлистов — позиция элемента.
- [ ] Все опции yt-dlp достижимы из UI (реестр ~280 опций), пресеты сохраняют наборы опций.
- [ ] Ошибки показываются классом и человекочитаемым текстом; `DRM_PROTECTED` → сообщение про DRM + «Показать лог».
- [ ] Логи/команда не содержат паролей/cookies (маскирование).
- [ ] Второй запуск активирует первое окно, дублей нет.
- [ ] EN/RU переключается без перезапуска (или с явным перезапуском — фиксируется в ACCEPTANCE), нет непереведённых строк.
- [ ] Светлая и тёмная темы; Material 3 Expressive.
- [ ] Windows 10/11 x64 и Linux X11/Wayland собираются (CI-матрица) и работают.
- [ ] yt-dlp/ffmpeg не входят в дистрибутив; их можно скачать/указать в Settings.
- [ ] Single-instance, параллелизм ≤ настройки, восстановление очереди после рестарта.
- [ ] `./gradlew build` зелёный включая тесты.
